# Thư mục bài nộp

Mỗi bạn tạo thư mục mang mã của mình trên nhánh cá nhân, ví dụ `submissions/hv001/`. Không sửa file này hoặc thư mục bạn khác trong PR nộp bài.

Cấu trúc bắt buộc và nội dung từng tệp được mô tả trong [mục 7 của đề](../docs/FINAL_PROJECT_SPEC.md). Quy trình tạo nhánh, mở PR và chốt bài nằm trong [README chung](../README.md).
